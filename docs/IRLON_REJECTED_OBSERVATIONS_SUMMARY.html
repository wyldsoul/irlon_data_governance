9. SBE37 enforcement

The rejection API verifies the private source row, stores its row_id, and suppresses only the named SBE37-owned public parameter. The public guard derives _SITE_SBE37 from SITE-WQ, fails closed if an active decision has no private match, then forces each rejected value to NULL and its paired qc_* field to the stored flag. A blank raw serial is preserved as blank provenance and does not block this.

Derived parameters

A rejected temperature_water creates SBE37 salinity and dissolved_oxygen children with the same QARTOD flag. If a matching private SeaFET observation exists at the same mapped station/time, it also creates a ph_tempsal child with that SeaFET source row ID and flag. No SeaFET row does not block SBE37. Reinstating the SBE37 parent deactivates its linked children but never reconstructs historical public values.
